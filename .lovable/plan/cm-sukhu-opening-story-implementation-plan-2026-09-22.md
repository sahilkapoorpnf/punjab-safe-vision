# CM Sukhu Opening Story — Implementation Plan

## Goal
Add a strong, evidence-led opening sequence before the existing NashaMukt Himachal presentation, designed specifically for a meeting with Hon’ble CM Thakur Sukhvinder Singh Sukhu.

## New opening sequence
1. **Leadership & Sankalp** — full-bleed real CM Sukhu photograph, his anti-chitta vision, and a restrained Hindi-English opening line.
2. **Government Action Timeline** — dated milestones covering the STF, zero-tolerance policy, PIT-NDPS enforcement, community mobilisation, police modernisation, and rehabilitation/prevention measures.
3. **Action → Measurable Results** — an official-source scorecard with only date-stamped, attributable figures; policy announcements and achieved outcomes will be clearly separated.
4. **Ground Reality / News Evidence** — a clean editorial collage of real official/news screenshots, each retaining its publisher, headline, and date, to establish urgency without sensational imagery.
5. **The Digital Force Multiplier** — connect the government’s existing work to NashaMukt Himachal: one intelligence layer for anonymous citizen inputs, repeat-location detection, command response, case tracking, and CM-level visibility.

## Visual direction
- Premium government briefing style using the current red, blue, and white system.
- Authentic CM/event photography and original webpage screenshots; no AI-generated portrait or fabricated news card.
- Hindi-English mix with short, presentation-ready statements.
- Every claim carries a visible source/date; detailed source links remain available on-screen.
- Mobile layout remains readable, with the existing presentation continuing immediately after the new introduction.

## Technical details
- Add five focused slide components and register them before the current title slide.
- Store downloaded public visuals locally in the project; do not hotlink.
- Add keyboard navigation and URL-synced slide position while preserving the existing bottom controls.
- Verify the complete opening flow at desktop and the currently viewed mobile width, checking image crops, source legibility, and navigation.
